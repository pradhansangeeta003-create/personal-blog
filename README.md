# 📝 Personal Blog Web Application

> A full-stack personal blog application built with **Python, Flask, HTML, CSS,  and SQLite**.

🌟 About The Project

The **Personal Blog Web Application** is a web-based platform that allows users to create and manage their own blog posts.

Users can register for an account, log in securely, create new posts, view their posts, edit existing posts, and delete posts when required.

The project demonstrates the practical implementation of **web development, user authentication, session management, database operations, CRUD functionality, and frontend design**.

 ✨ Key Features

- 🔐 User Registration and Login
- 🚪 Secure Logout
- 👤 Session-Based User Authentication
- 📊 Personalized User Dashboard
- ✍️ Create Blog Posts
- 👀 View Blog Posts
- ✏️ Edit Existing Posts
- 🗑️ Delete Posts
- 💬 Flash Messages
- 🗄️ SQLite Database Integration
- 🎨 Responsive and Simple User Interface
- 🔒 Users can manage their own posts

⚙️ How the Project Works
1. 📝 User Registration
New users can create an account by providing their required details. The information is stored in the SQLite database.
2. 🔐 User Login
Registered users can log in using their credentials. Flask sessions are used to maintain the user's login state.
3. 📊 Dashboard
After login, users can access their dashboard and manage their blog posts.
4. ✍️ Create Post
Users can create and publish new blog posts through the create post page.
5. 🖊️ Edit Post
Users can update their own existing blog posts.
6. 🗑️ Delete Post
Users can delete their own blog posts from the application.
7. 🔄 Dynamic Pages
Jinja2 is used to display database information dynamically inside HTML pages.
8. 🗄️ Database
SQLite stores user accounts and blog post information.
